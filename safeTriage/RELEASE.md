安诊 safeTriage 0.5.0，适用于 Windows 11 x64。

- 交替检测多个站点时，每个站点都保留本次会话中的上次结果，回到原站点可继续复查。
- 故障时间线按 Windows 事件记录匹配，同一秒内的同类事件可分别对比。
- 应用不使用代理与使用系统代理设置返回不同 HTTP 状态码时，摘要会显示各自的状态码。
- 网络排查和断网录制会在开始检测前提示端口 0 无效。

下载 `safeTriage-Setup-Windows-x64.exe` 可打开中文安装向导，选择安装目录和桌面快捷方式。安装后可通过 Windows「已安装的应用」卸载。

下载 `safeTriage-Windows-x64.exe` 可直接运行便携版。两种版本均附 SHA-256 校验文件。
